01 / THE PROJECT

A smoother path
from code to live site.

This project demonstrates a practical CI/CD workflow for a static web application. A change pushed to the main branch starts GitHub Actions, which packages the site files and deploys them to GitHub Pages over HTTPS.

✳

The goal: reduce repetitive deployment steps, make releases consistent and show the core building blocks of a modern DevOps workflow.
